# Executive Thought Leadership Agent

An AI-powered Article Studio that enables C-level executives to generate authentic, executive-grade LinkedIn articles in their own voice. Built on FastAPI and a LangGraph ReAct orchestration layer over watsonx.ai with a Carbon React UI, it combines live Tavily web research, a structured SOUL.md voice profile, and an ExecutiveIntelligenceLayer to produce thought leadership content that carries real executive gravitas — with six editing actions to refine tone, style, and specificity.
