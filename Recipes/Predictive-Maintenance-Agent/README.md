# Predictive Maintenance Agent (watsonx Orchestrate)

A real, deployable watsonx Orchestrate native agent that watches factory equipment telemetry, predicts the failure mode and remaining useful life, recommends parts and a technician, and auto-creates a maintenance work order when risk warrants — all embedded in a thin Carbon UI shell via Orchestrate web chat. It ships ADK artifacts (native agent + `@tool` tools) and five synthetic machines with preset critical, watch, and healthy scenarios for a legible, end-to-end agentic demo.
