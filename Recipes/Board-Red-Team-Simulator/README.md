# Board Red Team Simulator

An executive decision-intelligence app that pressure-tests a strategic proposal before the boardroom by having five AI personas — CFO, Activist Investor, Regulator, Competitor, and Independent Board Member — challenge it in parallel. Built on a LangGraph multi-agent workflow over watsonx.ai with an executive-grade Carbon UI, it returns a board-ready memo with risks, missing facts, the strongest challenge, and a 90-day validation plan, plus optional live market-signal enrichment.
