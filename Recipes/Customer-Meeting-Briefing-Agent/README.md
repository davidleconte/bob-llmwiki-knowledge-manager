# Customer Meeting Briefing Agent

An executive briefing agent that combines public financial signals, uploaded company filings (10-K / 20-F / annual reports), and meeting context into a concise, meeting-ready briefing in under a minute. Built on FastAPI and a LangGraph orchestration layer over watsonx.ai with a Carbon React UI, it delivers financial KPI cards, strategic priorities, talking points, recommended questions, and document-driven Executive Insights for high-stakes customer conversations.
