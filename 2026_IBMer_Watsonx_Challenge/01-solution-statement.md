As a Global Product Specialist on IBM's Worldwide watsonx.data Tiger Team for South EMEA, I spend most of my working week helping enterprises in Southern Europe, the Middle East, and Africa navigate one of the most technically demanding transitions in enterprise IT: moving from legacy data warehouses to a modern, open lakehouse architecture. The problem is not the technology. The problem is the pace. Each new client engagement — a bank in Riyadh, a telco in Lagos, a sovereign wealth fund in Abu Dhabi — brings the same architectural questions, the same integration patterns, the same real-time pipeline decisions that I and my colleagues have already answered, documented in Slack threads, and then lost. The next engagement starts from scratch. And I pay that cost again, and again, and again — in time, in Bobcoins, and in the client seconds I cannot give back.

**Team BobjectifLune** — inspired by Tintin's *Objectif Lune*: the belief that what seems impossible becomes achievable through curiosity, a fail-fast mindset, and resilience. IBM Bob is the tool that makes the impossible journey real.

Our project — **Mnemox** — gives IBM Bob a memory.

Every Bob session today starts from zero. Bob re-reads the same architectures, re-derives the same decisions, and re-explains the same concepts — because nothing it learned in the last session survived. Every Bobcoin spent on re-derivation is a Bobcoin not available for going deeper, researching further, or tackling a problem that genuinely requires sustained agentic effort.

**BobjectifLune** fixes that. We built a living, structured knowledge base — a growing library of concepts, decisions, findings, and guides — that persists across every Bob session. When Bob starts a new session, it retrieves what the team already knows instead of re-deriving it. The knowledge compounds: each session builds on the last rather than starting from scratch. For the Tiger Team, this means every new South EMEA engagement starts from the full accumulated expertise of the team — patterns, constraints, sizing rationale, regional specifics — rather than from zero.

The result is two things at once: lower Bobcoin cost for routine questions, and a genuinely expanded research frontier — the ability to tackle complex, multi-session, agentic problems that would previously have been too expensive to attempt with Bob.

It works natively in **IBM Bob IDE** and **IBM Bob Shell CLI** — no plugins, no MCP servers, no external services. Deploying to any project workspace requires a single command (`scripts/init-project.sh`) that scaffolds the KB structure and registers the mode in Bob IDE in under 30 seconds. After that one step, any IBMer on any team activates the mode from the mode picker — permanently, for that workspace. The intelligence is IBM Bob's — Mnemox gives Bob the institutional memory it needs to use that intelligence without repeating itself. The optional Python Token Optimization System goes further, but the KB Manager runs entirely in Bash and requires nothing beyond Bob.

This is not a tool that *uses* Bob as a backend — it is *built into* Bob as native modes. Mnemox only exists because Bob's mode system, `AGENTS.md` schema layer, and skill ecosystem make a persistent, disciplined, cacheable memory possible. Remove Bob and there is no product. This submission was drafted using the tool it describes; the knowledge base at `docs/knowledge-base/` — 90+ documents — was created and maintained by the Knowledge Manager mode itself. The GitHub repository is the proof of concept judges can inspect.

It has already proved itself in the author's own work. This is a single-IBMer proof of concept — the submission shows what one practitioner demonstrated, not a rollout. The team's first real use was on **hcd-at-its-core** — a platform of 94 interactive demos and 15 masterclasses training architects, engineers, and operators on the hardest real-time data problems in the industry. With the KB Manager loaded, Bobcoin spend per iteration cycle dropped by approximately 60% (measured from session cost readouts). Every Bobcoin recovered was reinvested into richer, deeper, more ambitious scenarios that would previously have been too expensive to attempt. That is the value proposition, lived — honestly, by one person, on one project, at full scale.

Because on the way to the impossible, you cannot afford to forget what you already learned.
