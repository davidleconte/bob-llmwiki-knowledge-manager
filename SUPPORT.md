# Support

Thanks for using `bob-llmwiki-knowledge-manager`. Here is how to get help.

## Documentation first

Most questions are answered in the docs:

- **Start here:** [`docs/README.md`](docs/README.md) — the Diátaxis navigation
  spine (Tutorials / How-to / Reference / Explanation).
- **Getting started:** [`docs/tutorials/optimize-a-prompt.md`](docs/tutorials/optimize-a-prompt.md).
- **Architecture:** [`docs/architecture/ARCHITECTURE.md`](docs/architecture/ARCHITECTURE.md).
- **API reference:** [`docs/api/`](docs/api/).
- **Project status & maturity:** [`STATUS.md`](STATUS.md).

## Asking a question

- **Usage questions and ideas:** open a **GitHub Discussion** (if enabled) or a
  GitHub issue using the appropriate template.
- **Bug reports:** open a GitHub issue with the **Bug report** template — include
  your Python version, the command you ran, and what you expected vs. saw.
- **Feature requests:** open a GitHub issue with the **Feature request**
  template.

Issue templates live under
[`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/).

## Security issues

**Do not** report vulnerabilities in public issues. Follow
[`SECURITY.md`](SECURITY.md) — use GitHub Private Vulnerability Reporting.

## What is supported

This is a small open-source project maintained on a best-effort basis. Response
times are not guaranteed; see the good-faith targets in `SECURITY.md` for
security reports. Supported Python versions are **3.11 and 3.12**.
