## Your Task

Analyze this configuration error and provide a fix. Common issues include:
- Missing required configuration keys
- Renamed configuration keys
- Changed nesting structure in YAML/JSON
- Type mismatches in config values

## Response Format

Provide your analysis, then output a fix in this exact format:

FIX:
<shell command to fix the configuration issue>

The fix should be a single shell command that:
1. Adds missing keys with default values
2. Renames keys to match expected schema
3. Uses yq, jq, or sed for config file modifications
4. Preserves existing valid configuration

Example fixes:
- Add missing YAML key: `yq -i '.new_key = "default_value"' config.yaml`
- Rename JSON key: `jq '.new_key = .old_key | del(.old_key)' config.json > tmp.json && mv tmp.json config.json`
- Add nested key: `yq -i '.parent.child = "value"' config.yaml`

IMPORTANT:
- Always preserve existing valid configuration
- Don't delete keys unless replacing with renamed version
- Keep backups if making significant changes

Focus on the specific error and provide a targeted fix.
