## Your Task

- Type mismatches

## Response Format

Provide your analysis, then output a fix in this exact format:

<shell command to fix the database issue>

The fix should be a single shell command that:
1. Runs a SQL migration or fix via sqlite3/psql/mysql CLI
2. Or modifies the query in the script
3. Is safe (no DROP DATABASE, no data loss)

Example fixes:
- Add missing column: `sqlite3 db.sqlite "ALTER TABLE users ADD COLUMN email TEXT;"`
- Rename column: `sqlite3 db.sqlite "ALTER TABLE users RENAME COLUMN old_name TO new_name;"`
- Fix query in script: `sed -i 's/old_column/new_column/g' script.py`

IMPORTANT: Never suggest:
- DROP DATABASE or DROP TABLE without backup
- DELETE without WHERE clause
- Modifications to production databases without confirmation

Focus on the specific error and provide a targeted fix.
