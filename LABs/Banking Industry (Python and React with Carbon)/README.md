# Banking — Core Banking Architecture & Code Understanding (Python/FastAPI)

A code-understanding lab built on the GFM Bank Core Banking System (FastAPI backend with teller and back-office clients), showing how IBM Bob analyzes complex banking codebases, API architecture, and transaction logic. Across three parts you generate stakeholder-ready architecture documentation with Mermaid diagrams, document functional requirements and data flows, and capture system invariants in a comprehensive ARCHITECTURE.md.
