# IMS (Information Management System)

Use this skill when working with IMS databases or transactions on IBM mainframe.

## Core Topics

### IMS DB (Database)
- Hierarchical database structure
- Segments and parent-child relationships
- DL/I calls (GU, GN, GNP, ISRT, REPL, DLET)
- PCBs (Program Communication Blocks)
- PSBs (Program Specification Blocks)
- DBDs (Database Descriptions)

### IMS TM (Transaction Manager)
- Message processing programs (MPP)
- Batch message processing (BMP)
- IMS transactions
- Message queues

## Best Practices
- Understand the hierarchical path before coding DL/I calls
- Use proper PCB selection for each program
- Handle status codes after every DL/I call
- Design segments to minimize I/O and improve performance
