# IBM Platform Integration

A comprehensive skill package for integrating IBM enterprise technologies and platforms.

## Included capabilities

- watsonx AI integration patterns
- OpenShift deployment and orchestration
- WebSphere application server configuration
- DB2 database integration
- MQ messaging patterns
- IBM Cloud services integration
- Security with Vault
- Data governance with Knowledge Catalog
- Hybrid cloud architectures

## Usage

Install this skill with:

```bash
bobmodes install-skill ibm-platform-integration
```

Project installs are copied into:

```text
<install-path>/
```

## Example prompt

> "Integrate our new watsonx.ai model with the existing OpenShift application. The model needs to process documents from MQ queues and store results in DB2."

Bob will provide the integration architecture, MQ consumer configuration, watsonx.ai API client code, and DB2 result persistence patterns.
