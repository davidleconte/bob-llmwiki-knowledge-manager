# DB2 for z/OS

Use this skill when working with DB2 databases on IBM mainframe systems.

## Core Topics
- SQL queries (SELECT, INSERT, UPDATE, DELETE)
- Embedded SQL in COBOL
- DECLARE CURSOR and cursor processing
- Static vs dynamic SQL
- DB2 stored procedures
- DB2 triggers and user-defined functions
- Table spaces and indexes
- BIND process and packages
- DB2 utilities (LOAD, REORG, RUNSTATS)
- Performance tuning and EXPLAIN

## Best Practices
- Use parameterized queries to avoid SQL injection
- Create appropriate indexes for query performance
- Use EXPLAIN to analyze and optimize query access paths
- Run RUNSTATS regularly to keep optimizer statistics current
- Use REORG to maintain table space efficiency
- Design table spaces and indexes for concurrent access
