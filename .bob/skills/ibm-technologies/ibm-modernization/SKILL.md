# IBM Modernization

A skill package for modernizing IBM enterprise applications and adopting modern IBM technologies.

## Included capabilities

- Application modernization strategies
- AIOps implementation patterns
- Root cause analysis automation
- IT log analysis and monitoring
- FinOps cost optimization
- Carbon Design System implementation
- Langflow AI workflow design
- Smart Data Platform integration
- Business automation workflows (BAW/BPMN)
- Quantum computing with Qiskit

## Usage

Install this skill with:

```bash
bobmodes install-skill ibm-modernization
```

Project installs are copied into:

```text
<install-path>/
```

## Example prompt

> "Modernize our IBM WebSphere monolith to run on OpenShift using the strangler-fig pattern, integrating with watsonx.ai for intelligent document processing."

Bob will outline the strangler-fig decomposition strategy, identify seams for service extraction, and provide the OpenShift deployment configuration and watsonx.ai integration patterns.
