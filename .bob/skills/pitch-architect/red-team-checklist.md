# Red-Team Checklist

Review any draft against these flags, then deliver a tighter version.

## Voice and framing

- [ ] Any "we / us / our" phrasing — rewrite into "you get / you can."
- [ ] Any named product, brand, or SKU — translate to capability + value.
- [ ] Solution or partner named before the need is fully built.
- [ ] Opening that starts with the seller instead of the audience's goal.

## Structure

- [ ] More than 3 core points.
- [ ] Features-first messaging — reorder as Means → Do → Is.
- [ ] Gain presented before pain.
- [ ] Known facts posing as unconsidered needs (if the audience already says it in their own meetings, it doesn't count).

## Claims

- [ ] Unprovable "only us" claims — soften or cut.
- [ ] Value parity presented as differentiation.
- [ ] Claims not tied to a KPI the audience personally owns.
- [ ] Statistics presented as audit numbers instead of directional hooks.

## Delivery

- [ ] Slides/visuals with more than one idea.
- [ ] Fear without a way forward.
- [ ] Speaker notes that don't end with a pull to the next beat.
- [ ] Missing the success test: would this audience finish by asking "so how would you make that possible?"
