# Software Project Example

This example demonstrates how to use Bob Shell Knowledge Manager for a software development project.

## Scenario

A team building a microservices-based e-commerce platform using:
- Backend: Python, FastAPI
- Database: PostgreSQL
- Cache: Redis
- Message Queue: RabbitMQ
- Infrastructure: Kubernetes, AWS

## Knowledge Base Structure

```
docs/knowledge-base/
├── INDEX.md                    # Main index
├── concepts/
│   ├── microservices.md       # Architecture concept
│   ├── event-driven.md        # Event-driven architecture
│   └── cqrs-pattern.md        # CQRS pattern
├── guides/
│   ├── setup-guide.md         # Development environment setup
│   └── deployment-guide.md    # Deployment procedures
├── references/
│   └── api-reference.md       # REST API documentation
└── research/
    └── caching-strategies-2026-07.md  # Performance research
```

## How to Use This Example

1. **Review the Documents**: Examine each document to see how templates are applied
2. **Understand Cross-References**: Notice how documents link to each other
3. **Adapt for Your Project**: Use this structure as a starting point
4. **Customize**: Modify templates and structure to fit your needs

## Key Takeaways

- **Concepts** document architectural patterns and design decisions
- **Guides** provide step-by-step instructions for common tasks
- **References** document APIs, configurations, and technical specs
- **Research** captures investigation results and findings

## Next Steps

1. Copy this structure to your project
