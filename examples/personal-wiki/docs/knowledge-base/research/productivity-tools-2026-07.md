# Productivity Tools Research

**Date:** July 2026
**Status:** Ongoing

## Objective
Evaluate productivity tools and workflows to improve personal efficiency.

## Tools Evaluated

### Note-Taking

**Obsidian:**
- Markdown-based
- Local-first
- Graph view
- Plugins ecosystem
- **Rating:** 9/10

**Notion:**
- All-in-one workspace
- Databases
- Collaboration
- Cloud-based
- **Rating:** 8/10

### Task Management

**Todoist:**
- Simple interface
- Natural language input
- Cross-platform
- **Rating:** 8/10

**Things 3:**
- Beautiful design
- macOS/iOS only
- One-time purchase
- **Rating:** 9/10

### Time Tracking

**Toggl:**
- Simple tracking
- Reports
- Integrations
- **Rating:** 8/10

### Code Editors

**VS Code:**
- Extensions
- Git integration
- Free
- **Rating:** 9/10

**Vim:**
- Fast
- Keyboard-driven
- Learning curve
- **Rating:** 8/10

## Current Setup

**Daily Workflow:**
1. Morning: Review tasks in Things 3
2. Work: Code in VS Code, track time in Toggl
3. Notes: Document in Obsidian
4. Evening: Review and plan next day

**Tools Stack:**
- Note-taking: Obsidian
- Tasks: Things 3
- Time tracking: Toggl
- Code: VS Code + Vim
- Knowledge: Bob Shell Knowledge Manager

## Findings

**What Works:**
- Markdown for everything
- Local-first tools
- Keyboard shortcuts
- Minimal context switching

**What Doesn't:**
- Too many tools
- Cloud-only solutions
- Complex workflows
- Proprietary formats

## Next Steps
- Integrate tools better
- Automate repetitive tasks
- Simplify workflow
- Regular reviews
