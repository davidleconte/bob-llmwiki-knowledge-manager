# Personal Wiki Example

This example demonstrates how to use Bob Shell Knowledge Manager as a personal knowledge management system.

## Scenario

An individual building a personal wiki to:
- Document learning and discoveries
- Track technical skills and tools
- Maintain how-to guides
- Research topics of interest
- Build a second brain

## Knowledge Base Structure

```
docs/knowledge-base/
├── INDEX.md
├── concepts/
│   ├── docker-containers.md
│   └── functional-programming.md
├── guides/
│   ├── git-workflow-guide.md
│   └── vim-setup-guide.md
├── references/
│   └── cli-commands.md
└── research/
    └── productivity-tools-2026-07.md
```

## How to Use This Example

1. **Personal Learning**: Document concepts as you learn them
2. **Quick Reference**: Create guides for tasks you do repeatedly
3. **Tool Documentation**: Maintain references for tools and commands
4. **Research Notes**: Track investigations and findings

## Key Takeaways

- **Concepts** capture ideas and theories you're learning
- **Guides** document your personal workflows and setups
- **References** provide quick lookup for commands and APIs
- **Research** tracks your explorations and experiments

## Next Steps

1. Start with topics you frequently reference
2. Add guides for your common workflows
3. Build up over time as you learn
4. Review and update regularly
